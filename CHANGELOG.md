# Changelog

- Live dashboard (water/solar temperature, filtration, heating) with push updates
- Controls: setpoint, manual pump, light (AUX, with automatic pump start), ECO, modes, backwash
- Timers & advanced settings: filtration, backwash, ECO and AUX time slots, durations, ECO reduction
- English, French and German UI
- MQTT bridge with Home Assistant discovery
- Home Assistant add-on with ingress and automatic Mosquitto discovery
